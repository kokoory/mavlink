# Architecture documents

| File | What it is |
| --- | --- |
| `KM-GCS-Architecture-v0.1.pdf` | the baseline design document |
| `KM-GCS-Architecture-v0.1.txt` | extracted text, for grep and diff |
| `adr/` | decisions taken while implementing it |

The ADRs are the authority where they disagree with the baseline. Each one
states the evidence for the change; six of them exist because the baseline was
implemented rather than only read.
